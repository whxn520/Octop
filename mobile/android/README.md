# Octop Android Chat

Native chat client (login + threads + WebSocket + FCM). See [docs/ARCHITECTURE.zh.md](../docs/ARCHITECTURE.zh.md).

```bash
# Open in Android Studio, or:
cd mobile/android
./gradlew :app:assembleDebug
```

Optional:

- Drop AGenUI AAR into `app/libs/`
- Add `app/google-services.json` for FCM
